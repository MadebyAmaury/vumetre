# Vu-mètre Audio-Mixer

Vu-mètre en direct de la board Audio-Mixer-MIDI (firmware ≥ 1.3.0) par USB, via Web Serial.

Ouvrir https://madebyamaury.github.io/vumetre/ dans **Chrome ou Edge**, brancher la board en USB,
cliquer « Connecter » et choisir le port de l'ESP32-S3 (USB JTAG/serial debug unit).
Rien à installer ; Safari et Firefox ne gèrent pas Web Serial.
